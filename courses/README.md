# courses/

Your subjects live here, one directory per course (`courses/<course-id>/`).

Everything in this directory except this README and the two starter courses is
**gitignored**: lecture material and generated study content never leave your machine. The
starter courses `opamp-grundlagen` and `how-bitcoin-works` come with the repository so that
`just dev` has something to show; delete them when you do not want them (`git rm -r`). Create a course with
`/register-new-subject <folder>` in Claude Code, or a single topic without an exam with
`/register-new-topic <path>`.
